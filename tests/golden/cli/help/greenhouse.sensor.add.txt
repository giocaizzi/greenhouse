
 Usage: greenhouse sensor add [OPTIONS]

 Add a sensor to a cluster.

╭─ Options ────────────────────────────────────────────────────────────────────────────────────────╮
│ *  --cluster          <int>  Cluster ID [required]                                               │
│ *  --device-id        <str>  Tuya device ID [required]                                           │
│ *  --name             <str>  Sensor name [required]                                              │
│ *  --type             <str>  Device model key (tuya.tr301z) [required]                           │
│    --plant-id         <int>  Associated plant ID                                                 │
│    --help                    Show this message and exit.                                         │
╰──────────────────────────────────────────────────────────────────────────────────────────────────╯
