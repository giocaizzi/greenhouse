
 Usage: greenhouse config set [OPTIONS]

 Patch a cluster's irrigation config. Omitted options are left unchanged.

╭─ Options ────────────────────────────────────────────────────────────────────────────────────────╮
│ *  --cluster                         <int>  Cluster ID [required]                                │
│    --mode                            <str>  manual, schedule, or smart                           │
│    --minutes                         <int>  Duration in minutes                                  │
│    --interval                        <int>  Interval in hours                                    │
│    --auto-run       --no-auto-run           Enable auto-run                                      │
│    --daily-cap                       <int>  Daily cap in minutes                                 │
│    --max-events                      <int>  Max irrigation events per day                        │
│    --quiet-start                     <int>  Quiet-hours start (0-23); equal to end = disabled    │
│    --quiet-end                       <int>  Quiet-hours end (0-23, exclusive)                    │
│    --help                                   Show this message and exit.                          │
╰──────────────────────────────────────────────────────────────────────────────────────────────────╯
