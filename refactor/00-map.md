## 2. Public symbols and consumers per module

Names only. *Consumers* = internal modules importing it (any form, incl. lazy) and test files importing it or patching a dotted path inside it. `‡` = public top-level name with **no by-name reference outside its module** in prod or tests (imports, attribute access, string refs) **and none inside it either** — dead-code candidates; `§` = public name referenced only inside its own module (could be `_private`, but renaming changes import surface — rule 6). Verify before acting. Route handlers, CLI commands and Alembic revisions are registered by decorator and never flagged.

## 3. Entrypoints

### Console scripts
- `greenhouse` → `greenhouse_cli.main:app` (Typer) — `libs/greenhouse-cli/pyproject.toml`.

### FastAPI app factory — `greenhouse_server/app.py:create_app(settings=None, engine=None)`
Order of construction (all of this runs for **every** server test via `tests/server/conftest.py::_make_stubbed_app`):
1. `Settings()` if none; `create_db_engine(settings.db_url)` if no engine; `init_db(engine)` (Alembic upgrade to head).
2. `lifespan`: if `settings.enable_scheduler` → `start_scheduler()` + `rearm_leak_checks()`; on exit `stop_scheduler()`.
3. `FastAPI(title='Greenhouse API', version='1.0.0', openapi_tags=[…14], generate_unique_id_function=lambda r: r.name)` — operationId = route function name.
4. `app.state`: `settings`, `session_factory`, `device_gateway` + `device_registry` (`_init_tuya`: `DeviceGateway()` → `build_default_registry`; both `None` on any exception), display tz from `UserPreferences.timezone` (`_startup_timezone` → `set_display_timezone`), `weather_client` (`WeatherClient(lat, lon, tz)`), `ntfy_notifier` (only if URL+topic), `plant_db` (`_init_plant_db`).
5. `init_scheduler(app, settings, tz_name)`, `init_health_monitor(app, settings)` (→ `app.state.health_monitor`, only if registry), `_restore_persisted_scheduler_pause(app)`.
6. `bootstrap_admin(engine, settings)`.
7. Routers: `routes.auth` unprotected at `/api/v1`; 21 API routers at `/api/v1` with `dependencies=[Depends(require_user)]`; `well_known` at root; `/static` mount; `web_router` (web.router: `web.routes.auth` unprotected, 18 others behind `require_web_user`); `register_web_exception_handlers(app)`.
8. `FastApiMCP(app, name='greenhouse', auth_config=AuthConfig(dependencies=[Depends(require_mcp_token)]))`, `mount_http()` → `/mcp`; stored on `app.state.mcp`.

### Scheduler — `greenhouse_server/scheduler.py`
Module-global `scheduler = BackgroundScheduler(job_defaults=_JOB_DEFAULTS)` (`misfire_grace_time=None, coalesce=True, max_instances=1`) and `_app`. Registration via `_add_core_job(func, trigger, id=, name=, replace_existing=True)`:

| job id | func | trigger | registered in |
|---|---|---|---|
| `sensor_sync` | `_sync_job` | interval, `settings.sync_interval_minutes` (default 180) | `init_scheduler` |
| `check_all` | `_check_job` | cron `hour=_resolve_check_cron_hours(settings)`, `minute=0` (tz-bound) | `_add_tz_bound_cron_jobs` (also on `reschedule_for_timezone`) |
| `plant_health_snapshot` | `_health_snapshot_job` | cron 00:30 (tz-bound) | `_add_tz_bound_cron_jobs` |
